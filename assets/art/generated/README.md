# Generated Art Assets

This folder stores project-bound bitmap assets generated for the Codex Spirit Companion art direction.

## taotie-mascot-v1-512.png

- Tool: built-in `image_gen` through the `imagegen` skill.
- Purpose: polished mascot reference for improving the current rough art direction.
- Source role: art reference and share-card/preview asset, not yet a full runtime animation sprite.
- Background: generated on a flat magenta chroma-key background, then converted locally to a transparent PNG.
- Prompt summary: cute chibi jade Taotie spirit pet, polished pixel-game sprite style, thick dark outline, cream belly, gold horns, coral blush, forehead gem, jade pendant, small scroll pack, no text, no watermark.

The local `*-chromakey.png` intermediate files are ignored by Git.
